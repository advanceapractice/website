Your signature, fixed

The old signature embedded its images as base64 data: URIs, which Gmail, Outlook and Yahoo all strip from received mail — so the logo and all three icons vanished together. This one points at hosted files instead. Copy it, paste it into Gmail, done.

Preview

Shown on white, the way it lands in an inbox. Same artwork you were already using — recovered from your sent mail, nothing redrawn.

Install it

  1. In Gmail, open Settings → See all settings → General and scroll to Signature.
  2. Select everything in the existing signature box and delete it. Leftover fragments are what usually cause a doubled logo.
  3. Click Copy signature above, click into the empty box, and paste.
  4. Scroll to the bottom and click Save Changes — Gmail discards the edit otherwise.
  5. Send a test to one Gmail address and one Outlook address. Apple Mail is not a valid test: it renders the broken kind too.

Two things worth knowing

Don't paste images straight into the signature box. That is what produced the data: URIs in the first place. If you ever need to change the artwork, replace the file behind the URL instead.

The images are served from your public GitHub repo, pinned to a commit so the URLs never move. That works today with no setup. When convenient, upload the four files in email/brand/ to WordPress and swap the URL prefix — your own domain is the better long-term home. Steps are in email/README.md.
